# 2026-10-16：XunChi 开发更新

## 实际变化

| 改善 | 使用效果 | 证据 |
|---|---|---|
| 公司启动页、产品名与终端标题 | 启动页显示 `xunchi-IC-agent`，窗口和任务栏显示 `XunChi` | 用户 CentOS 7 截图 |
| 简化启动与恢复入口 | 使用 `xunchi-agent-centos7`，退出恢复提示也走兼容入口 | 源码补丁、运行检查 |
| 旧终端兼容层 | 拦截不支持的探测协议并恢复 tty 状态，退出不再留下探测乱码 | 真实 TUI/PTY 测试；用户目标机反馈 |
| 安装、校验、备份与回退 | 新版本放入独立用户目录，保留旧入口及模型配置 | 安装器集成测试与真实成品隔离安装测试 |
| 运行记录原型 | 独立任务、退出码、超时和保守的 LVS 结果解析 | 单元/进程测试；尚未接入正式 agent 工具 |

已有另一位实习生成功使用原兼容环境。用户也确认当前 agent 可操控 Virtuoso。新的接收者仍需自己的 EDA 环境、bridge 配置、模型服务和权限；公开源码不包含这些部署资产。

## 可公开复用的内容

- `xunchi-agent-centos7/deploy/`：安装与终端兼容代码。
- `xunchi-agent-centos7/patches/`：固定上游提交上的品牌及构建补丁。
- `xunchi-agent-centos7/src/`：启动检查和异步任务执行原型。
- `xunchi-agent-centos7/tests/`：23 项测试。
- 构建、安装、架构与验证说明，以及不含凭据的部署模板。

内部成品版本为 `0.1.0-brand.3`，此版本号区分于原 r1 Release 和 `0.1.0-dev.1` 开发原型。此次没有上传内部二进制安装包，也没有修改旧 r1 Release 资产。目录中的构建记录是已构建内部包的记录，不表示本仓库已有对应的公开 Release。

## 验证范围

开发机为 WSL Ubuntu；Python 3.6 语法检查与现代 Python 测试均有记录。目标 CentOS 的运行结果来自用户命令、截图及明确反馈。没有发布完整设计、Calibre 报告或模型会话，不宣称版图 DRC/LVS 已通过。具体器件布局进度不在本次公开更新中记录。
